                    Basic RAG Chain:
                    chain structure:
==================================================================================
{
context,   |  prompt   |  LLM   | parser
questions  | (Template)| model  | output
}          |           |        |
===================================================================================
context --> is external , verified data (like companys docs or db) retrieved by the system
question --> the users prompt or query

===========================================================================
parallel input processing
context  <-- Retreiver
question <-- Runnable Passthrough --> means donot modify anything when it comes to questions
Questions passes through unchanged

===========================================================================
                PROMPT TEMPLATE
---------------------------------------------------------------------------

{context}

===========================================================================
                Handling "I dont know"
===========================================================================
Without instruction:
Q.what is quantum computing?
--> Quantum computing uses qubits..."(makes up answer)
-------------------------------------------------------------------------
With Instruction:
Q.What is quantum computing?
--> I dont have information about that in the provided context.
==========================================================================
                The prompt Pattern
==========================================================================
Answer based only on the following context
If the context doesnot contain the answer ,say "i dont have information about that".
context:{context} Question{question}
